category Main Concepts

Supervised Learning

Training models using labeled datasets where the desired output is known. E.g., predicting house prices.

Unsupervised Learning

Finding patterns in unlabeled data. Grouping similar items without prior knowledge. E.g., customer segmentation.

Reinforcement Learning

Agents learn to make decisions by performing actions in an environment to maximize a reward. E.g., game playing AI.

Features & Labels

Features are independent variables (inputs), labels are dependent variables (outputs we want to predict).

format_list_bulleted Detailed Notes

1. Traditional Programming vs. Machine Learning

  • Traditional: Data + Rules = Answers. A human writes explicit rules (code) to process data.
  • Machine Learning: Data + Answers = Rules. The system learns the rules by analyzing examples of data and the expected answers.

2. The Machine Learning Pipeline

  • Data Collection: Gathering raw data from various sources.
  • Data Preparation (Crucial step): Cleaning data, handling missing values, and formatting. "Garbage in, garbage out."
  • Model Selection: Choosing the right algorithm (e.g., Linear Regression, Decision Tree) based on the problem type.
  • Training: Feeding data to the model so it can adjust its internal parameters to minimize error.
  • Evaluation: Testing the model on unseen data to assess its generalization capability.

3. Key Challenges

  • Overfitting: Model memorizes training data; performs poorly on new data. (Analogy: Memorizing a math textbook but failing the exam because questions are slightly different).
  • Underfitting: Model is too simple to capture underlying patterns in the data.
  • Data Bias: If training data is biased, the resulting model will inherit and amplify those biases.
